# T-Mates Grocery WRC

WRC 零售服务机器人工作区，当前代码按原始 ROS 2 工作区结构保存在 `src/`。

## 主要模块

- `src/control/`：抓取流程、预设姿态与设备管理网页。
- `src/hand_eye_calibration/`：手眼标定采集、计算与网页工具。
- `src/navigation/`：零售导航消息、桥接节点和 HTTP 接口。

各模块的安装、配置和启动方法请查看对应目录中的 README。

## 本地数据

标定数据集、抓取采样、相机快照、编译目录和运行日志不会提交到 Git。它们由根目录 `.gitignore` 排除，并继续保留在采集设备本地。

## 硬件配置

仓库中的相机序列号、机械臂 IP、串口、地图坐标和绝对路径均为现场设备配置。部署到其他机器人前，必须根据实际硬件和目录进行核对及调整。
