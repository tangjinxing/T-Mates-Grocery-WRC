# WRC 导航启动与操作指令

> 适用：华汇悟时底盘 + `WRC/src/navigation` 下的 `retail_nav_bridge`  
> 底盘 IP：`169.254.128.2`，机器人 ID：`10001`  
> 当前地图：`hj1`，储位：`mark_0` / `mark_1` / `mark_2`（vendor_mark：`0` / `1` / `2`）

---

## 0.1 一键启动（推荐）

在 `navigation` 目录下已提供脚本，等价于终端 A + B + C：

```bash
cd ~/WRC/src/navigation

# 启动 agent + bridge + Init/Relocate，并等待 HTTP 网关就绪
./start_navigation.sh

# 停止全部导航进程
./stop_navigation.sh
```

启动成功后可直接用 HTTP：

```bash
curl --noproxy '*' http://127.0.0.1:8081/navigation/health

curl --noproxy '*' -X POST http://127.0.0.1:8081/navigation/navigate \
  -H 'Content-Type: application/json' \
  -H 'Idempotency-Key: nav-001' \
  -d '{"target_id":"mark_0"}'
```

脚本选项：

| 选项 | 含义 |
|------|------|
| `./start_navigation.sh` | 先停旧进程，再启动并执行 Init/Relocate |
| `./start_navigation.sh --skip-init` | 只启动 agent/bridge，不执行 Init/Relocate |
| `./start_navigation.sh --no-restart` | 不先停旧进程（若已在跑会报错退出） |

日志目录：`~/WRC/src/navigation/logs/`（`agent.log`、`bridge.log`）

## 1. 环境（每个终端先执行）

```bash
source /opt/ros/humble/setup.bash
source ~/WRC/install/setup.bash
export ROS_DOMAIN_ID=0
```

`ROS_DOMAIN_ID=0`：agent 与 bridge 必须在同一 ROS 频道，才能互相发现。

---

## 2. 启动 agent

**终端 A：**

```bash
ros2 run woosh_robot_agent agent --ros-args \
  -r __ns:=/woosh_robot \
  -p ip:="169.254.128.2"
```

agent 是 ROS 与悟时底盘（5480）之间的翻译层，不可省略。

---

## 3. 启动 bridge（WRC 配置）

**终端 B：**

```bash
ros2 launch retail_nav_bridge woosh_bridge.launch.py \
  params_file:=$HOME/WRC/src/navigation/retail_nav_bridge/config/nav_defaults_woosh.yaml \
  stations_file:=$HOME/WRC/src/navigation/retail_nav_bridge/config/retail_stations.yaml \
  target_mapping_file:=$HOME/WRC/src/navigation/retail_nav_bridge/config/product_slot_navigation.yaml \
  http_host:=0.0.0.0 \
  http_port:=8081
```

bridge 提供 HTTP 网关（8081）和统一导航门面 `/retail_nav/v1/*`。

---

## 4. 初始化并确认 READY

**终端 C：**

```bash
ros2 service call /retail_nav/v1/Init retail_nav_msgs/srv/Init "{}"

ros2 service call /retail_nav/v1/Relocate retail_nav_msgs/srv/Relocate "{}"

curl --noproxy '*' http://127.0.0.1:8081/navigation/health
```

期望输出：`{"status":"READY"}`

说明：

- 刚启动时通常为 `STARTING`，完成 Init + Relocate 后才应变为 `READY`。
- 若底盘处于建图、故障、电机过热等不可任务状态，Init 可能失败，需先在上位机处理。

## 9. 说明

### `--noproxy '*'`

若本机配置了 `http_proxy`，curl 访问 `127.0.0.1:8081` 或 `169.254.128.2` 可能失败；加 `--noproxy '*'` 可直连。也可：

```bash
unset http_proxy https_proxy HTTP_PROXY HTTPS_PROXY
```

### curl 参数简要

| 参数 | 含义 |
|------|------|
| `-X POST` | 使用 POST 方法 |
| `-H 'Content-Type: application/json'` | 请求体为 JSON |
| `-H 'Idempotency-Key: ...'` | 幂等键，重复请求不重复执行物理动作 |
| `-d '{...}'` | 请求体 JSON 数据 |

### agent 与 bridge 代码位置

| 组件 | 路径 |
|------|------|
| agent（二进制，deb 安装） | `/opt/ros/humble/lib/woosh_robot_agent/agent` |
| bridge 源码 | `~/WRC/src/navigation/retail_nav_bridge/` |
| HTTP 网关 | `~/WRC/src/navigation/retail_nav_bridge/retail_nav_bridge/http_gateway.py` |
| 悟时适配 | `~/WRC/src/navigation/retail_nav_bridge/retail_nav_bridge/adapters/woosh.py` |
